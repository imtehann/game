# Chess Famous Games & Puzzles Website

This repository contains a **static Jekyll site** that showcases ten iconic chess games with full tactical breakdowns, Stockfish 17 analysis, and a puzzle engine.

## Features
- Detailed markdown pages for each game (move‑by‑move commentary, key tactics, and Stockfish evaluation).
- Player bios with mental‑principle highlights.
- Puzzle page offering:
  - Random puzzles generated from the full game database.
  - Curated puzzles per famous player.
- Simple, responsive design generated with Jekyll (can be hosted on GitHub Pages).

## Getting Started
1. **Install Ruby & Bundler** (if not already installed).
2. **Install Jekyll**:
   ```powershell
   gem install bundler jekyll
   ```
3. **Install dependencies**:
   ```powershell
   cd C:/Users/nazim/.gemini/antigravity/scratch/chess_famous_games
   bundle install
   ```
4. **Run the helper scripts** (requires Python 3.10+ and Stockfish 17 in your PATH):
   ```powershell
   python scripts/download_games.py   # fetch PGNs for the 10 games
   python scripts/analyze_game.py    # generate Stockfish analysis files
   python scripts/generate_puzzles.py# create puzzle JSONs
   ```
5. **Build the site**:
   ```powershell
   bundle exec jekyll build   # output in _site/
   ```
6. **Preview locally**:
   ```powershell
   bundle exec jekyll serve
   ```
   Open `http://localhost:4000` in your browser.

## Adding More Games
- Append a new entry to `data/games.json`.
- Add a markdown file under `games/` following the existing templates.
- Re‑run `scripts/analyze_game.py` to generate fresh Stockfish analysis.
